# Automated Financial Risk Analyzer 📈

## Overview
**Automated Financial Risk Analyzer** is a professional-grade analytics suite designed to bridge the gap between high-level financial engineering and modern software development. [cite_start]Leveraging my **Master's in Financial Engineering & Risk Management** [cite: 49] [cite_start]and ongoing **ICT studies at Metropolia University**[cite: 46], this tool automates the extraction, cleaning, and statistical analysis of financial data.

[cite_start]This project is part of my professional portfolio, demonstrating my ability to build modular Python systems [cite: 13] [cite_start]and implement complex data-driven logic[cite: 10].

## Key Features
* [cite_start]**Live Data Ingestion:** Fetches real-time market data via RESTful APIs[cite: 27, 41].
* **Statistical Engine:** Calculates volatility, correlation matrices, and risk metrics using **Pandas** and **NumPy**.
* **Probability Analysis:** Implements probability distributions to model market variability.
* [cite_start]**Data Validation:** Integrated cleaning engine to handle outliers and missing financial values[cite: 22, 40].
* [cite_start]**Database Integration:** Persistent storage for historical analysis using **SQLite/PostgreSQL**[cite: 18, 47].
